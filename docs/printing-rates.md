# Print availability and rush pricing

- A saved print price of zero means that paper/color combination is not offered. Customer rate tables show an em dash, offer no selection control for that cell, and server quotations reject it, including forged or stale selections. Staff can set a positive rate to offer it again.
- If any file requests rush printing, the order rush surcharge is 20% of the entire printing subtotal, charged once per order. The subtotal includes document pages and copies. Delivery is excluded from the percentage and added separately.
- Percentage results are rounded half up to two decimal places after calculating the order-level percentage. For example: PHP 100.00 printing + PHP 20.00 rush + PHP 30.00 delivery = PHP 150.00.
- The shop must still enable the Rush Printing service. No editable flat rush fee is required or used. Legacy flat-fee records can remain in the database, but fee forms cannot change rush pricing and customer displays show the percentage.
- Existing placed orders keep their saved price and payment snapshots. No database migration or rewrite of existing orders is required.
